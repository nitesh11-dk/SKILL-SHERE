# 🔁 Skill-Sharing Barter Platform

A MERN stack-based web application where users can **exchange skills** instead of paying with money. The platform enables peer-to-peer learning through a **barter system**, allowing users to teach and learn skills by scheduling sessions with one another.

## 🌟 Features

- 👤 User Profile Creation  
- 🧠 Skill Listing & Browsing  
- 🔍 Send Requests to Learn Other Users’ Skills  
- 📅 Schedule Sessions Using a Custom-Built Calendar  
- ✅ Accept/Reject Session Requests  
- 🔐 Secure Authentication (JWT & bcrypt)  
- 📱 Responsive UI for Smooth User Experience  

## 🚀 Tech Stack

| Layer        | Technology          |
|--------------|---------------------|
| Frontend     | React.js            |
| Backend      | Node.js, Express.js |
| Database     | MongoDB             |
| Authentication | JWT, bcrypt.js    |
| Calendar     | Custom-coded UI (AI-assisted) |
| Deployment   | Render              |
